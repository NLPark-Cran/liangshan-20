## 三、作品分四块

### 1. 长卷（主体）

横向展开的浙江生态地图。卷首是全省，六个点位在真实经纬度上。往右拖，一站一站看过去。

每一站有：
- 一幅手绘场景（代码绘制，不是图片）
- 一段故事
- 3—6 条数据，每条都标了出处
- 一句引文

### 2. 一亩山的账本（推演游戏）

一座山从开矿到关矿再到复绿的二十年。第 4 年会问你：矿要不要关。关了就不可逆，当年现金立刻掉到十位数。

玩到底看两个数：村集体年收入、山还剩多少。

### 3. 观鸟观测手账

选一个浙江的观鸟点，翻一条观测记录。记录里有地点、日期、天气、风向、鸟种、数量和辨识要点。稀有度按真实记录频率分级（常、有、稀、迷、神）。

「台风过境」按钮会抽出被台风从海上吹进内陆的迷鸟。

### 4. 等一只鸟回来（招引游戏）

中华凤头燕鸥的招引。选岛、摆假鸟、放声音，然后等。鸟来不来不由你决定。

守五季，看这座岛飞出几只雏鸟。这个游戏不能「赢」。

## 六、技术说明

- 纯前端 + 轻后端
- 前端：原生 JavaScript + Canvas 2D，无框架、无构建步骤
- 后端：Node 24 + Hono + TypeScript，PostgreSQL 17 + Redis
- 部署：Caddy 反代，systemd 托管，无容器
- 全站零位图：所有画面由代码绘制，随分辨率重算

**为什么不用框架**：这个项目的交互复杂度不高，框架带来的收益小于复杂度成本。零构建还有个好处：老师或评审在任何机器上打开都不会因为构建产物出问题而白屏。

## 八、本地怎么看

```bash
cd map-site/site
python -m http.server 8000
```

然后打开 http://127.0.0.1:8000。**必须用 HTTP 服务，不能双击 index.html**——ES Module 在 file:// 下会被浏览器拦。

如果要用后端功能，需要同时跑 server 并配好数据库。
