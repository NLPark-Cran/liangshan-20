## 一、设计立意

**一句话**：把「绿水青山就是金山银山」画成一幅可以展卷的浙江山水长卷。

中国山水画的观看方式是「手卷」——不是一眼看全，而是一段一段展开。这个动作本身就在说一件事：**理解一条路要走完才知道它通向哪里。**

所以本站的交互不是「缩放地图」，而是「展卷」。

## 四、手绘感的实现：三条必须遵守的规则

### 4.1 山脊的峰顶必须圆

**这是本项目踩过最深的坑。** 前后改了六轮才找到根因。

错误的做法（都试过，都失败）：
- 提高采样密度 → 无效，因为顶点本身就是折角
- 加平滑滤波 → 无效，平滑只能把折角磨钝，不能让它变圆
- 减小 crest 指数 → 只能缓解，本质没变
- 用 `Math.abs(sin)` 或正弦叠加 → 出来是波浪

**根因**：峰形公式在顶点处的导数不为零。

```js
// 错误：k=1 时导数是 (foot + crest*(crest-foot))/crest，不收敛到 0
v = (foot * k + (crest - foot) * Math.pow(k, crest)) / crest;

// 正确：k=1 时值取 1、导数必为 0
v = 1 - Math.pow(1 - k, p);
```

**记这条**：任何要画「圆的东西」的公式，先验算端点导数。导数为零才是圆，不为零就是尖的。

### 4.2 脊线必须整条一次画完

切段绘制会在段与段的接缝处留下折点。峰顶正好落在接缝附近时尤其明显。

而且密集采样点用 `lineTo` 连接也是折线。用二次贝塞尔：

```js
// 每个点取与前后点的中点作为终点，当前点作控制点
ctx.quadraticCurveTo(cur[0], cur[1], midX, midY);
```

### 4.3 雾是「擦掉墨」，不是「画上白」

用 `destination-out` 把墨擦掉，宣纸自己承担雾。这样永远没有白色硬边。

**陷阱**：`destination-out` 必须 clip 在山体内。不 clip 就会把画布下半部整片擦白——这不是留白，是消失。

## 五、图元库的分工

| 文件 | 职责 |
|---|---|
| `brush.js` | 最底层笔触：抖动、飞白、多层叠压、确定性随机 |
| `inkcurve.js` | 平滑曲线（二次贝塞尔），解决折线问题 |
| `inkfig.js` | 水墨图元：山、树、水、屋、船、桥、梯田、大棚 |
| `scenes.js` | 六个点位各自的构图 |

**依赖方向**：`scenes` → `inkfig` → `inkcurve` → `brush`。不能反向依赖。

## 七、导出的构图约束

导出用 900×600 逻辑尺寸（4 倍超采样到 3600×2400）。

- 地图区域：`x: 20%, y: 7%, w: 66%, h: 86%`
- 左侧留 20% 给竖排题名
- 右上角放指北
- 右下角放印章（62px，四个字）

**不要用 `fitWidth`**：按宽度铺满会让高度超出画布，顶部被裁掉。
