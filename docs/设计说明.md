## 一、作品是什么

## 二、为什么是这个形式

### 2.1 手绘的落点在「画出来」

课程要求「手绘创作加工的原创绘画图案，不得简单以照片、模型、线稿代替」。这幅图里没有任何一张照片、任何一张位图。所有的山、水、树、屋、田，都是代码一行行画出来的：墨色分层叠压、线条沿法向抖动、笔触按概率断开留白。用的是中国画的语言，皴法、留白、题跋、印章。

这样画出来的图不会糊。屏幕多大，它都重新算一遍，按比例重画。

### 2.2 手卷要一段一段展开

手卷不能一眼看全，必须一段一段看过去。

「两山」也是这样。2005 年关矿的时候，余村人看不见二十年后的样子，只是做了一个在当时看起来很不划算的决定。所以这里的交互是展卷，不是缩放。缩放是看一张图，展卷是读一段路。

### 2.3 三个时间尺度

只讲一件事容易讲空，所以把同一件事拆成三个尺度：

| 模块 | 时间 | 说的是 |
|---|---|---|
| 长卷 | 空间，一屏一屏 | 浙江六个地方各做了什么 |
| 一亩山的账本 | 二十年，一年一年 | 为什么要关矿，代价怎么扛 |
| 鸟 | 一年一季，反复 | 保护靠什么维持下去 |

余村的故事激励人心，但它是少数。更多的地方没有那样戏剧化的转折，只有一块地、一条溪、一片林子，年复一年地照看。三个尺度放在一起，生态文明才不至于讲成一个励志故事。

## 三、六个地方

按长卷顺序：

| 序 | 点位 | 它回答的问题 |
|---|---|---|
| 一 | 钱江源（衢州开化） | 一条江的源头，先被让出来。上游让出来的东西，下游看不见，但下游喝的水从这里开始。 |
| 二 | 下姜村（杭州淳安） | 一个穷山村，把猪圈换成了民宿。转折不靠一个项目，是把一件件小事做完。 |
| 三 | 余村（湖州安吉） | 一座山关掉了一半，账本换了一种算法。「绿水青山就是金山银山」在这里被说出来。 |
| 四 | 新溪桥村（杭州临安） | 一块菜地，租给城里人。生态能不能变成一门持续的生意，困难都很具体。 |
| 五 | 浦江（金华浦江） | 一条河从劣五类治回三类。有时候生态修复不是加法，是减法。 |
| 六 | 云和梯田（丽水云和） | 一千年的田，没有荒掉。它的价值不在好看，在于它是一套还在运转的系统。 |

**新溪桥村是本组实地调研点。** 这一站的素材（村集体收入、共享菜园面积、认养用户数量）来自实地走访与村级调研反馈表，其余五个点位是公开资料。

## 四、视觉语言

### 4.1 色彩

全部取自中国画的颜料名：

| 色 | 值 | 用在哪 |
|---|---|---|
| 焦墨 | `#1c1f1d` | 标题、重点数字 |
| 宣纸 | `#f4efe4` | 底色，所有留白 |
| 远水青 | `#6d8f8a` | 水 |
| 竹青 | `#7c9160` | 生态、正增长 |
| 赭石 | `#b1813f` | 矿、土地、负向 |
| 朱砂 | `#9d3a30` | 印章、交互焦点 |

六个色相，都是低饱和的自然色。数据图表也用这套。

### 4.2 字体

标题与题跋用楷体（有书写感），正文用宋体（长期阅读不累），数字与标注用黑体（小字号下清晰）。

### 4.3 留白

中国画里的留白承担着内容，所以段落间距宁大勿小，宁可少写一段。

## 五、三件配套小东西的设计

### 5.1 一亩山的账本

一座山被炸开卖石头，村集体一年进三百多万；后来矿关了，收入掉到二十几万；再后来，山养回来了，人回来了。

玩家要自己扛那个「掉下去」的时刻。关矿做成一个不可逆的选择，点了就不能反悔，当年现金立刻断崖。在山还没养回来的那几年，什么都长不出来。

时间是这个游戏唯一的参数。它要说的是：生态本身能挣钱，只是账期很长。

> 注：参数是示意，不是真实账目。真实的账比这复杂得多，也慢得多。

### 5.2 观鸟观测手账

它的设定是：每抽一次，就是翻到一条真实的观测记录。

一条记录包含地点、时间、天气、风向、鸟种、数量、辨识要点。稀有度不另造一套游戏稀有度，直接按真实记录的频率分级：常、有、稀、迷、神。

「迷」这一档是迷鸟。台风过后，远洋的海鸟会被吹进内陆，观鸟人连夜出门去追。观鸟圈里真有这回事。

### 5.3 等一只鸟回来

中华凤头燕鸥，民间叫「神话之鸟」，全球极危。浙江象山的韭山列岛做过一件很像游戏的事：在岛上摆假鸟，用太阳能设备回放叫声，把远洋的燕鸥引到岛上繁殖。

玩家能做的只有三件事：选岛、摆假鸟、放声音。鸟来不来，不由玩家决定。

这个游戏不能「赢」。最好的结果是屏幕上几只鸟安静地留在那儿。这比任何分数都更贴近保护工作的本质。

## 六、长征精神怎么接

长征路上很多地方，现在是生态要地。若尔盖草地当年是红军付出生命代价才走出去的沼泽，今天它是黄河上游重要的水源涵养地。九十年前人和自然的关系是生死考验，今天是和谐共生。

时间上，长征胜利 90 周年、两山理念 20 周年、十五五开局、杭电建校 70 周年，四个时间点叠在一起。一代人有一代人的长征路，今天这条路上有一段叫生态文明。

## 七、技术说明

- 前端为原生 JavaScript 与 Canvas 2D，不使用任何框架，零构建步骤
- 后端为 Node + Hono + TypeScript，PostgreSQL 与 Redis，用于保存成绩与排行榜
